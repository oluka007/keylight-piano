Let’s set up your keyboard

Three quick checks, then your first lesson.

Later, in the player, − and + at the top right move your keys an octave down or up. Z and X do the same.

To install it you need Homebrew (brew.sh). Paste these two lines into Terminal, then quit and reopen Keylight:

brew install uv python@3.13
uv tool install --python /opt/homebrew/bin/python3.13 --from "git+https://github.com/hyperb1iss/blocksd@main" blocksd
