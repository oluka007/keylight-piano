# App Store screenshots

Real screens from the iOS Simulator (Debug build, clean install, status bar set with `xcrun simctl status_bar ... override --time 9:41 --batteryState charged --batteryLevel 100 --wifiBars 3 --cellularBars 4`). No device frames, no edits.

| Folder | Simulator | Size (portrait) | Apple slot (checked against App Store Connect help, "Screenshot specifications") |
|---|---|---|---|
| `ipad-13/` | iPad Pro 13-inch (M5) | 2064 x 2752 | iPad 13" (required for iPad) |
| `ipad-11/` | iPad Pro 11-inch (M5) | 1668 x 2420 | iPad 11" (optional: Apple scales the 13" set) |
| `iphone-6.9/` | iPhone 17 Pro Max | 1320 x 2868 | iPhone 6.9" (required for iPhone) |

Seven screens each: 01 Home, 02 Course map, 03 a lesson, 04 an exercise (the Find the Key note game on the on-screen keys), 05 the player (falling notes and sheet music), 06 the library filtered to Chopin, 07 Settings. Portrait only (Apple accepts one orientation); landscape was reviewed in QA but not exported.
